# Apache Spark SPIP Compatibility Matrix

## Supported Spark Versions

| Spark Version | Scala Version | Python Version | Catalyst AST Status | Native Accessor |
|:--------------|:--------------|:---------------|:--------------------|:----------------|
| 3.3.4         | 2.12          | 3.8 - 3.10     | Fully Supported     | Supported       |
| 3.4.3         | 2.12 / 2.13   | 3.9 - 3.11     | Fully Supported     | Supported       |
| 3.5.1         | 2.12 / 2.13   | 3.9 - 3.12     | Fully Supported     | Supported (v0.2)|

All releases maintain binary compatibility with PySpark DataFrame extensions.
